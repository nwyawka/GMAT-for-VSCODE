# Installing on another Mac

No Git client is required.

1. On the GitHub repository page, open **Releases**.
2. Download `gmat-headless-0.5.3.vsix` from the latest release.
3. In VS Code, open Extensions, select the `…` menu, and choose **Install from VSIX…**.
4. Select the downloaded file and reload VS Code.
5. Run **GMAT: Select Installation** and choose `GmatConsole` if it is not found automatically.

The VSIX is self-contained. GMAT must be installed separately; Python and Git are not required.
